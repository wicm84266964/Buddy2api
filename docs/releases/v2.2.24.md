# Buddy2api v2.2.24

修复 Loomy 长会话中的空思考消息兼容问题，并缓解上游瞬时 502/503 或断连导致账号立即冷却、客户端连续重试失败的问题。

- 发送 Loomy 请求时过滤只有 reasoning_content、没有正文、工具调用或拒绝内容的 assistant 消息；保留正常回答、工具调用和对应思考内容，不修改原始请求。
- 流式和非流式请求在收到响应头前断连，或上游返回 HTTP 502/503 时，关闭失败连接并等待 0.5 秒，向同一账号原样重试一次；第一次失败不立即冷却账号。
- 第一次失败保留 retry 日志且不重复计入请求用量；成功响应继续记录 token 和上游返回的积分。
- 已接收响应头后的流消费错误不重放，避免重复输出或工具调用。400、401、429、504 不经过本次新增重试；持续故障仍会按既有流程报错。
- 增加消息兼容、连接关闭、重试次数、流中断、日志与积分统计回归测试，以及维护排查记录。

本版用于缓解已复现的请求兼容问题和上游间歇故障，不能保证消除 Loomy 持续性服务异常。

验证：Windows 本地完整测试 930 项通过，干净源码副本语法编译通过；长会话诊断副本经本地网关连续 3 次成功，token 与积分记录正常。

更新并重启服务后生效。

正式镜像：`ghcr.io/wicm84266964/buddy2api:v2.2.24`（`linux/amd64`）。正式发布同时更新 `latest`。
