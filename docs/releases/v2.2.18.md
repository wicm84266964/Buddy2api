# Buddy2api v2.2.18

发布日期：2026-11-06

本补丁修复流式回复结束、客户端断开及请求取消时的资源清理，并补齐 Loomy 会话被提前撤销后的密码重新登录。

## 流式响应

- 将账号绑定限制在单次读取和关闭操作内，避免异步生成器跨任务关闭时出现 `Token was created in a different Context`。
- 模型名转换、Chat 流回放和 Responses 转换逐层关闭上游，包括首次发送前就关闭的情况。
- Responses 收到 `[DONE]`、无效事件或上游错误时主动释放连接。
- 两个流式 HTTP 端点在客户端断开或请求取消后执行受保护、有超时限制的关闭操作。
- 预读首个事件时取消请求，也会关闭已创建的上游流，并继续传递取消信号。

## Loomy

- 本地会话尚未到期但上游返回 401/403 时，使用已保存的加密密码尝试重新登录一次。
- 验证从客户端发现的较新会话，不再仅凭本地时间将保活判为成功。
- 没有保存密码时仍需重新导入有效会话；429、服务端错误及网络异常不会触发密码重登。

## 升级与验证

无需数据库迁移。发布版本和镜像不会自动重启现有服务；新代码在更新并重启服务后生效。请等正在执行的任务结束后再重启。

本地完整测试 **727 项通过**，包含 Chat Completions 和 Responses HTTP 端点集成测试、跨任务关闭、客户端断开、请求取消及 Loomy 认证恢复。上游与登录均使用模拟响应，未调用真实账号。发布提交须通过 GitHub CI。

正式镜像为 `ghcr.io/wicm84266964/buddy2api:v2.2.18`，平台为 `linux/amd64`；正式发布工作流成功后同时更新 `latest`。
