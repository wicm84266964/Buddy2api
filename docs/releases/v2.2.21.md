# Buddy2api v2.2.21

修复千问办公请求异常处理中的 `EncodeError` 导入问题。

- 流式响应在返回上游错误后关闭时，不再因 `NameError` 重复输出 `Failed to close response stream`。
- 编码失败时，流式和非流式请求保留原始错误，按原有逻辑处理失败账号。
- 增加编码失败和上游报错后关闭响应的回归测试。

本次修复不解决上游登录失效或模型排队问题。更新并重启服务后生效。

验证：Windows 本地完整测试 802 项通过，Python 语法编译完成。测试使用模拟上游，不调用真实账号。

正式镜像：`ghcr.io/wicm84266964/buddy2api:v2.2.21`（`linux/amd64`）。正式发布流程同时更新 `latest`。
