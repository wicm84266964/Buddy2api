# Buddy2api v1.4.8

发布日期：2026-08-19

这个版本把出站请求升级为 Work Buddy / CodeBuddy 官方 CLI 客户端的完整请求头指纹。

## 新增内容

- **新增 `fingerprint.py`**：综合四份逆向参考实现（Go / TS / Python）的共识字段，统一构造三类上游请求头：
  - **Chat**：通用指纹（`X-Requested-With`、按账号域选择的 `Origin` / `Referer`、`X-Product: SaaS`、`X-Domain`、`X-Request-ID` / `X-B3-*` / `b3` 追踪头）+ 账号头（`Authorization`、`X-User-Id`、`X-Enterprise-Id`、`X-Tenant-Id`）+ CLI 指纹（`X-IDE-Type/Name/Version`、`x-codebuddy-request: 1`、`X-Agent-Intent: craft`、每请求生成的 `X-Conversation-*`）+ 官方 SDK 指纹（`x-stainless-*`）。
  - **Billing**：余额 / 积分接口改用精简指纹头。
  - **Refresh**：token 刷新接口使用专用指纹头，`X-Refresh-Token` 仅在此出现，并附带 `Cache-Control: no-cache` / `Pragma: no-cache`。
- **缺省字段用 `X-No-*` 标记**：与官方 CLI 一致，`uid` / `enterprise_id` / `domain` 缺失时发送 `X-No-User-Id: 1` 等标记而不是空值。
- **默认 User-Agent 改为官方 CLI UA** `CLI/2.109.2 CodeBuddy/2.109.2`（原为 `codebuddy2openai/2.0`），版本号随 `CB_GATEWAY_IDE_VERSION` 联动。

## 兼容与升级说明

- 无数据库结构变更，无迁移动作。
- 如上游不接受新 UA，设置 `CB_GATEWAY_USER_AGENT=codebuddy2openai/2.0` 即可回退到历史 UA。
- 指纹仅作用于请求头；如上游进一步校验 TLS 指纹（JA3），需额外部署支持 TLS 指纹模拟的转发层。

## 验证

- `python -m pytest -q`：86 passed。
- 手动验证：Chat / Billing / Refresh 三类头与参考实现逐字段比对一致；中国版 / 国际版账号的 `Origin` / `Referer` 按域自动切换。
