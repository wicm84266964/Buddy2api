# Buddy2api v2.2.17

发布日期：2026-11-05

本补丁版本合并 [PR #136](https://github.com/wicm84266964/Buddy2api/pull/136)，将按渠道配置上下文预裁剪预算接入管理页，无需仅依赖环境变量。

## 设置页改进

- 「上下文预算」新增渠道下拉框，可分别设置 WorkBuddy 国内／国际、Qoder 中国／国际、千问办公、TraeWork、Loomy 和小浣熊的预算。
- 新增「全选（全部渠道）」；输入预算后点击「应用到全部渠道」，再保存设置，即可批量配置。单独修改一个渠道不会改变其他渠道。
- 填 `0` 关闭发送前裁剪。默认保持 Loomy 160000 token，其他渠道（含 WorkBuddy 国内／国际）关闭预裁剪。
- 配置持久保存，保存后对后续请求生效，服务重启后恢复。请求派发读取内存快照，不新增数据库查询。
- 校验渠道与预算范围，预算须为 0 到 2000000 的整数。

## 配置优先级与兼容性

非 Loomy 渠道：`CB_PRETRIM_CHANNELS` 中对应渠道的值优先于管理页设置；`CB_PRETRIM_BUDGET` 只为未单独配置的渠道兜底。页面显式保存的 `0` 会关闭该渠道预裁剪，不再使用全局兜底。

Loomy 保留原有设置项，由 `CB_LOOMY_CONTEXT_BUDGET` 优先覆盖。预算包含输出预留，超过预算会删除更早历史，保留最新一段；不会修改模型列表宣告的容量，上游拒绝上下文后的补裁逻辑保持不变。

## 升级与验证

无需数据库迁移。更新代码或镜像后重启服务，并刷新管理页。

本地完整测试 **704 项通过**，编译及差异格式检查通过；7 个 Vue 模板编译和脚本语法检查通过。浏览器交互验证了全选批量应用、单渠道关闭及其他渠道预算不变。发布提交须通过 GitHub CI。

正式镜像为 `ghcr.io/wicm84266964/buddy2api:v2.2.17`，平台为 `linux/amd64`；发布工作流成功后同时更新 `latest`。
