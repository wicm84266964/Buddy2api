# Buddy2api v2.2.16

发布日期：2026-11-04

本补丁版本合并 [PR #134](https://github.com/wicm84266964/Buddy2api/pull/134)，将发送前上下文预算扩展为按渠道配置。**WorkBuddy 国内／国际默认不预裁剪，不设置 150000 token 默认预算。**

## 改进与修复

- 新增 `CB_PRETRIM_CHANNELS`，按渠道显式设置预裁剪预算，例如 `workbuddy=150000,qwenwork=80000`；`0` 表示该渠道关闭预裁剪。
- 新增 `CB_PRETRIM_BUDGET`，作为未列出渠道的全局兜底预算，默认 `0`（关闭）。
- 除 Loomy 沿用原有预算外，其他渠道需显式配置后才启用发送前裁剪。开启后会按预算删除更早历史，保留最新一段；预算值不是上游官方容量或限频保证。
- 修复裁剪后的预算复核：使用实际渠道预算，避免误用 Loomy 预算。
- 非法渠道预算按 `0` 处理，预算上限为 2000000 token。

## 升级与验证

无需数据库迁移。更新后重启服务；使用环境变量配置预算时，需要重启进程后生效。Loomy 原有设置和上游拒绝上下文后的补裁重试机制保持不变。

本地完整测试 **695 项通过**，覆盖 WorkBuddy 国内／国际长历史默认不裁、显式渠道预算及全局兜底。编译检查通过；发布提交须通过 GitHub CI。

正式镜像为 `ghcr.io/wicm84266964/buddy2api:v2.2.16`，平台为 `linux/amd64`。发布工作流构建成功后同时更新 `latest`。
