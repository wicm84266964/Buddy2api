# Buddy2api v2.2.20

发布日期：2026-11-09

本补丁整合社区 [PR #143](https://github.com/wicm84266964/Buddy2api/pull/143)，减少后台页面卡顿和额度概览的重复查询，并补齐并发额度更新与证书配置的回归保护。

## 性能优化

- **复用 TLS 上下文**：异步 HTTP 请求共用启动时加载的证书配置，避免每次创建客户端都同步加载证书，减少 Windows 下事件循环阻塞，以及额度查询、登录刷新和聊天请求对管理页面响应的影响。HTTPS 证书与主机名验证仍然启用。
- **额度概览缓存 5 分钟**：非 WorkBuddy 渠道成功查询的额度快照按渠道和账号缓存 300 秒，重复打开概览可直接读取缓存。到期后由下一次查询更新；强制刷新立即重新查询。失败结果不写入缓存，缓存命中也不会把旧余额重新标记成新测量。

## 修复与回归保护

- 缓存来源单独随调用返回，不再修改共享快照。多个概览请求并发时，新测得的零额度仍会写入路由额度缓存，避免耗尽账号继续参与调度。
- 分别维护遵循环境配置和忽略环境配置的 TLS 上下文，保留 Qoder 和 TraeWork 等 `trust_env=False` 请求原有的证书策略；支持 `SSL_CERT_FILE`、`SSL_CERT_DIR` 及前者优先的行为。
- 新增 9 项回归测试，覆盖缓存命中、强制刷新、到期、失败重试、字典与对象快照、并发零额度测量，以及不同证书环境下的信任策略。

## 升级与验证

无需数据库迁移或新增配置。额度概览在缓存有效期内可能显示旧余额，需要最新数据时请使用强制刷新。

Windows 本地完整测试 **799 项通过**，Python 语法编译通过。验证使用隔离数据库及模拟上游，未使用真实账号调用供应商接口。发布流程同时要求 GitHub 必需 CI 通过。

正式镜像：`ghcr.io/wicm84266964/buddy2api:v2.2.20`（`linux/amd64`）。正式发布流程同时更新 `latest`。更新与重启现有实例后生效。
