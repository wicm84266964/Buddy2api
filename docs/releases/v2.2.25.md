# Buddy2api v2.2.25

修复 WorkBuddy / CodeBuddy 官方余额在套餐已用尽后仍显示原套餐额度的问题，对应 [#149](https://github.com/wicm84266964/Buddy2api/issues/149) 与 [PR #150](https://github.com/wicm84266964/Buddy2api/pull/150)。

- 官方余额按 `remaining → available_total → total_dosage` 取可花费余额，并保留显式 0；账号列表、额度详情、Dashboard 通道余额和低余额提醒统一使用该口径。
- 未过期但已用尽的额度包显示为「已用尽」；失败或未知余额、额度包金额显示为 `—`，不再由 `credit(null)` 伪装成 0。
- 失败或不支持的资源不再产生假的 0 余额提醒。
- 增加 issue #149 回归覆盖：后端聚合、JS 显示 helper、额度包状态、模板契约与数据库隔离。

验证：本地完整测试 936 项通过；聚焦回归 87 项通过；Python 编译、Node helper 真值表、Vue 模板编译与 1366×900 浏览器 smoke 通过。PR #150 的 `test suite` 通过。

更新并重启服务后生效。

正式镜像：`ghcr.io/wicm84266964/buddy2api:v2.2.25`（`linux/amd64`）。正式发布同时更新 `latest`。
