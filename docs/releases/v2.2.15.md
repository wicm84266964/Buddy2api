# Buddy2api v2.2.15

发布日期：2026-11-02

本补丁版本合并 [PR #132](https://github.com/wicm84266964/Buddy2api/pull/132)，修复新版 WorkBuddy 桌面客户端的加密登录文件无法导入的问题。

## 修复

- 扫描 `.info` 文件时，按字段信封尝试客户端的包装密钥和 keyblob 主密钥。新版客户端使用包装密钥加密的 accessToken、refreshToken 等字段现在可以正常解密；使用主密钥的旧文件继续兼容。
- 取钥时仍校验当前 keyblob。客户端轮换密钥后，旧缓存失效并重新从运行中的客户端回收密钥。
- 密钥回收失败时保留统一的 at-rest 错误原因，避免将加密信封写入账号库。

## 升级与验证

Windows 本机导入加密登录文件仍需运行 WorkBuddy 桌面客户端，并允许读取其进程内存和 keyblob。Linux / Docker 无法直接读取 Windows 宿主机进程内的密钥。

本地完整测试 687 项通过；PR 和发布提交还需通过 GitHub CI。正式镜像为 `ghcr.io/wicm84266964/buddy2api:v2.2.15`，平台为 `linux/amd64`。发布工作流构建成功后同时更新 `latest`。
